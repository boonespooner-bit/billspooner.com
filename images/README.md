# Images

Drop photos here. Suggested layout:

```
/images/
  /hero/           Hero background shots (large, landscape)
  /about/          Portraits of Bill
  /tubes/          Band photos — live, studio, portraits
  /albums/         Album art / record sleeves
```

Keep files under ~400 KB each where possible. `.jpg` for photos, `.webp`
if you want smaller files. Aim for 2000px on the long edge for heroes,
1200px for gallery tiles.

See `README.md` at the repo root for how to swap these into the HTML.
